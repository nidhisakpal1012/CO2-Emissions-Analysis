# CO2 Emissions Analysis & Prediction

## 📌 Project Overview
This project analyzes CO2 emissions data and predicts future emissions using Machine Learning.

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## 📊 Analysis Performed
- CO2 trend analysis for India
- Top 5 emitting countries comparison
- India vs China emissions comparison
- Future prediction using Linear Regression

## 📈 Results
- CO2 emissions are continuously increasing
- India shows rapid growth after 2005
- Model predicts further rise in emissions

## 🚀 Project Output
Includes graphs and predictions for better understanding of emissions trend
